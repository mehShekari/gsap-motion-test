# GSAP Card Animation Benchmark

You are working in a small React application. Build a polished, premium animation system for the existing card section.

Requirements:
- Animate the existing 3 cards when the page first loads.
- The entrance should feel choreographed rather than simultaneous.
- Establish a clear visual focus on the featured card.
- Add a subtle, polished hover interaction to each card.
- Preserve the existing visual design; improve motion, not the content architecture.
- The experience must work on desktop and mobile.
- Respect `prefers-reduced-motion`.
- Use GSAP for the animation work. Do not add another animation library.
- Avoid unnecessary dependencies.
- Keep the implementation maintainable and safe across React re-renders/unmounts.

Constraints:
- Do not change the product copy.
- Do not replace the entire app with a different design.
- Do not use video or external assets.
- Verify the implementation with the project's available build tooling before finishing.

Goal: make the cards feel intentionally designed in motion, while keeping the animation restrained and performant.
